# アカウント設計（Instagram・Amazonストアフロント）

## コンセプト

**「選ぶときのチェックポイントがひと目でわかる、家事ラク・収納グッズの図解まとめ」**

- 顔出しなし・生活感なし。図解カルーセルで「保存される」アカウントにする
- 「何を買うか」より「どう選ぶか」を見せる。具体的な商品は Amazon のアイデアリストで見てもらう
- 「使ってみた」系の体験談は書かない（実際に使ったものだけ、後から追加していく）
- アカウント名・ユーザーネームに「Amazon」「アマゾン」は入れない（公式アカウントと誤解されるため）

## Instagram

楽天ROOM用に準備したアカウントをそのまま使い、名前・自己紹介・リンクを下の内容に差し替える。

### ユーザーネーム案（空いているものを使う）
1. `kurashi_raku_room`（楽天用に取っていればそのままでOK）
2. `raku_kurashi_note`
3. `kajiraku_zukan`

→ 決めたら `content/account.json` の `handle` も合わせる（画像右下に入る）。変えたあとは `npm run images -- --all --relabel` で焼き直せる

### 名前（検索に引っかかる語を入れる）
```
くらしラク図鑑｜家事ラク・収納グッズ図解
```

### 自己紹介（150文字以内）
```
家事ラク・収納グッズを図解でまとめてます🧺
✔ 選ぶときのチェックポイントつき
✔ 買う前に「保存」して見比べ用に
✔ 毎日21時に更新
▼紹介アイテムはAmazonのリストにまとめ中
Amazonのアソシエイトとして、くらしラク図鑑は適格販売により収入を得ています。
```
最後の1行はアソシエイトの開示文（運営規約 第5条）。キャプションにも毎回自動で入るけど、プロフィールにも置いておく。
アカウント名を変えたら、開示文の名前と `content/account.json` の `name` も同じにする。

### リンク
Amazonストアフロントの自分のページ（`https://www.amazon.co.jp/shop/xxxxxxx`）だけにする。リンクを増やすと迷わせるので1本に絞る。

### ハイライト（投稿がたまったら作る）
`洗濯` / `収納` / `キッチン` / `掃除` / `冬支度`
カバー画像は Gemini で同じ配色（オフホワイト＋セージグリーン）のアイコンを作る

### 固定投稿（最初の3本がたまったら）
保存数が多かったものを上位3つ固定する

## Amazonストアフロント

### 表示名
```
くらしラク図鑑
```

### 自己紹介
```
Instagram「くらしラク図鑑」で紹介した家事ラク・収納グッズを、投稿と同じ名前のリストにまとめています。
価格・在庫は各商品ページで最新の情報を確認してください。
（この紹介文はAIにより作成）
```

### アイデアリスト
インスタの投稿ごとに、投稿と同じ名前のリストを作る（`npm run storefront` でチェックリストが出る）。
1つのリストに2商品以上ないと保存できない。同じ商品ページの色違い・サイズ違いは1リストに1つまで。
